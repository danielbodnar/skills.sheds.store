Install

Add the marketplace once for your account, then install the plugin for yourself or for everyone in a repo:

claude plugin marketplace add {{BASE}}/marketplace.json
claude plugin install sheds-store@sheds-store
claude plugin install sheds-store@sheds-store --scope project

User scope is the default. --scope project writes .claude/settings.json in the repo, so everyone who opens it gets the plugin. In a session, the same commands work as /plugin ….

For claude.ai, Claude Desktop and Cowork:

    {{REPO_STEP}}
  • The whole plugin: sheds-store.zip, uploaded under Customize > Plugins.
  • One skill: its .skill file from the list on the right, uploaded under Customize > Skills.

Checksums for every file are in SHA256SUMS.

GitLab Duo, Codex, Copilot, OpenCode, Zed, pi, and anything else that reads .agents/skills. In a repo, or for your user with -g:

bunx skills@latest add {{BASE}} --all
bunx skills@latest add {{BASE}} --all -g

Codex, Copilot CLI, VS Code, Gemini CLI, pi and oh-my-pi can also install the plugin from its git repo. The README has the commands.

sheds.store work also uses vendors' own plugins. Install them from their own sources, so nobody ends up with two plugins of the same name:

/plugin install cloudflare@claude-plugins-official
/plugin install supabase@claude-plugins-official
/plugin install gitlab@claude-plugins-official
/plugin install resend@claude-plugins-official

Vue: /plugin marketplace add vuejs-ai/skills. 1Password: /plugin marketplace add 1Password/1password-claude-plugin. Google Maps: bunx skills@latest add googlemaps/agent-skills. GitLab CLI skills: glab skills install.

Every agent follows these rules. No React: interactive UI is a Vue Options API component mounted as an Astro island, styled with Tailwind and the theme tokens. Reuse the pricing helpers. Branch from develop and open the MR into develop with a Conventional Commit title. Agents open MRs; they don't merge, deploy or set production secrets.
